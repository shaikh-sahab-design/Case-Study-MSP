The project at a glance

Folio3 needed a new website for its Managed IT and Cybersecurity line, covering Managed IT, Managed Security and AI Security, with service pages, case studies, a blog and a contact flow.

A website like this usually moves through several hands. A designer makes the screens, a front-end developer builds them, a WordPress developer moves them into the CMS, and someone tests the result.

Here, one person carried it end to end. I designed the site in Figma, then directed Claude Code to turn the designs into a working, animated site. I reviewed every change through GitHub, rebuilt all pages as editable Elementor pages in WordPress, and checked the finished build.

10

The skills behind the work

Skills are reusable instruction sets that make Claude Code work to a standard. I installed, checked and in some cases wrote them before relying on them.

ui-ux-pro-max

UX rules and design patterns, used when designing new pages such as Thank You.

Design. Installed from GitHub and checked first.
figma-use  +  figma-generate-design

Let Claude Code read and write the Figma file directly, using its own components and styles.

Design and build
animate

Motion standards for React: smooth easing, springs for interactive parts, and reduced-motion support.

Build. Audited for hidden calls before use.
wordpress-code-review

A security-first review for WordPress code with a severity rating and fixes. Written for this project.

Testing. Created by the designer.
website-audit

A UX, conversion, SEO and accessibility audit for live websites.

Testing
skill-inspector  +  hallmark

One vets skills for unsafe code before they are installed. The other sets a design standard for new pages, including this document.

Safety and quality

Plain language in, working results out

The prompts were short and direct. The skill lies in knowing what to ask for, and in judging what comes back.

Setting up the toolkit, 26 Oct

https://github.com/nextlevelbuilder/ui-ux-pro-max-skill.git

install that skill

Claude cloned the repo, checked its scripts for network and shell calls, fixed a broken path, tested it and packaged it.

Keeping the tools honest, 29 Oct

I have a skill installed named "Animate". Can you check whether it has any extra code or commands that are taking more or extra credits? Or sharing credits with another account

Claude read all 14 files and scanned them for network calls, hidden commands and account references before the skill went near the code.
